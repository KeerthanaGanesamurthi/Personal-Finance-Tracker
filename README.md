# MoneyFlow - Personal Finance Tracker

**MoneyFlow** is a user-friendly personal finance tracker built with **React**. It helps you manage your income and expenses, track your balance, and visualize your spending habits with interactive charts. The app saves your data locally in the browser, making it fast and easy to use without any backend setup.

---

## Features

- Add, edit, and delete transactions
- Track income and expenses separately
- View current balance, total income, and total expenses
- Filter and sort transactions by date, amount, or category
- Visualize monthly income/expenses and spending by category using charts
- Responsive and modern UI with smooth animations
- LocalStorage integration for saving your data in the browser

---

## Tech Stack

- **Frontend:** React.js  
- **Charts & Visualization:** Chart.js, react-chartjs-2  
- **Styling:** CSS (with animations and responsive design)  
- **Data Storage:** Browser LocalStorage
